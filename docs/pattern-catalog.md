## 패턴 추가 기준

다음 항목을 모두 채울 수 있을 때만 카탈로그에 추가한다.

1. 사용자가 보는 한 문장 효과 설명
2. 시작·종료 경계 정의
3. 역스크롤 동작 정의
4. 모바일과 reduced motion에서의 대안
5. 첫 적용 화면 예시
